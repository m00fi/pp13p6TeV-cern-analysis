# Rozkłady cząstek w zderzeniach pp przy √s = 13.6 TeV

Symulacja zderzeń proton-proton w Pythii 8 i analiza cząstek końcowych w ROOT.
Projekt przechodzi od generacji około 100 000 zdarzeń minimum bias do histogramów
krotności, pT, η i φ oraz wykresów PNG i PDF.

## Środowisko

- ROOT 6.40.04 i Pythia 8.312 z kanału `conda-forge`
